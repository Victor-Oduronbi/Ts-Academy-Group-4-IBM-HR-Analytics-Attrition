# TS Academy Capstone Project - Group 04

## Project Overview
This repository contains the end-to-end data science pipeline for **Group 04**'s TS Academy Capstone Project. The goal of this project is to analyze employee turnover patterns and build predictive models using the **IBM HR Analytics Attrition** dataset.

## Dataset
* **Source:** IBM HR Analytics Attrition (Kaggle)
* **Target Variable:** `Attrition`

## Structure & Deliverables
The project is strictly contained in a single Colab notebook covering 7 key stages:
1. Part 1. Data Foundation (SQLite, SQL Queries, EDA, Cleaning)
2. Part 2. Feature Engineering and Encoding
3. Part 3. Clustering Analysis (K-Means & PCA)
4. Part 4. Classification
5. Part 5. Imbalance Handling
6. Part 6. The Tie-In
7. Part 7. Conclusion and Recommendations

## Rules & Constraints
* Entire workflow must execute clean end-to-end on Colab in < 20 minutes.
* Minimum target metrics: Beats stratified dummy baseline; Minimum ROC AUC of 0.75.
